# 0010 — Scope skill groups to their evidence

- Status: accepted
- Date: 2026-10-21

## Context

A technology list can blur the difference between skills used in employment, skills demonstrated in independent products, and engineering methods.

## Decision

Group skills by evidence context. Identify whether each group reflects work experience, independent projects, or engineering methods, and keep each claim within that context.

## Consequences

- The Stack describes where a skill is evidenced instead of implying that every skill was used in the same role.
- Group labels, supporting copy, and technology entries remain aligned in the MDX content.
